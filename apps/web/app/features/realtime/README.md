# 实时监控

本模块负责浏览器单例 WebSocket、最新传感器值和三张实时趋势图。服务端从 MQTT 接收数据、写入原数据库后，再通过 `/ws` 推送到这里。全部传感器趋势按分钟归并，温度和流量趋势保留每条实时报文的秒级时间点。

三张图共享同一份按设备隔离、按分钟去重、最多 120 点的缓存：

- 全部传感器趋势：所有可转换为有限数字的动态字段。
- 温度趋势：`temp_in` 与 `temp_out`。
- 流量趋势：`flow_rate`。

页面首次进入和 WebSocket 重连时复用传感器历史趋势接口补拉数据，不新增实时协议。
页面选中设备后会读取数据库最近一条传感器记录作为卡片初始值，随后由 WebSocket 实时数据覆盖。
