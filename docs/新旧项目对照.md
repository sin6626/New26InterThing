# 新旧项目对照

[返回 README](../README.md)

## 结论标记

- **已迁移**：业务含义保留，新项目以 TypeScript 模块重新实现。
- **有意改设计**：需求保留，但为安全性或可维护性改变了边界。
- **明确不迁移**：已确认不属于比赛交付范围。
- **等待外部资料**：已留出稳定配置边界，不猜测赛方协议。

## 页面与业务链路

| 业务 | 旧项目 | 新项目 | 结论 | 主要依据 |
|---|---|---|---|---|
| 实时传感器 | `/sensorData/realtime` | `/` | 已迁移 | `device/sensor` → `t_sensor_data` → `sensor.realtime` |
| 历史数据/趋势 | `/sensorData/past` | `/history` | 已迁移 | `GET /api/sensor-history` 及 `/trend` |
| 实时行为 MQTT | `/behavior/realtime` | 无独立页 | 有意改设计 | 赛方识别改为历史数据触发的 HTTP 链路 |
| 行为历史 | `/behavior/past` | `/behaviors` | 已迁移 | `t_behavior_field_mapper` + `t_behavior_data` |
| 故障信息 | `/error_data` | `/faults` | 有意改设计 | 设备不上报故障，后端规则统一写 `t_error_msg` |
| 设备管理 | `/device` 可增删改查 | `/device` 只读查询 | 有意改设计 | 设备维护由独立 `contest_admin` 负责 |
| 指令控制 | `/direct` | `/controls` | 已迁移 | 动态 `t_direct_config`，人工/自动共用后端安全门 |
| 指令历史 | `/direct/history` | `/operation-logs` | 已迁移 | `t_direct_history` |
| 测试页 | `/test` | 无 | 明确不迁移 | 不交付无业务引用的调试页 |
| 自动水循环/PID | 后端大型单文件 | `/controls` + 拆分后自动化模块 | 有意改设计 | 状态机、执行器、温控、安全和模式切换分层 |
| 累计水量 | 内存 + 建表逻辑 | `/controls` | 有意改设计 | 复用既有 `t_water_flow_accumulator`，应用不修改表结构 |
| 运行时长/升温速度 | 本地 JSON/热工派生服务 | `/controls` 进程内实时指标 | 有意改设计 | 只认设备实际反馈，服务重启后从零统计 |
| 设备在线 | 传感器活跃 + 可选心跳 | 仅传感器实时活跃 | 有意改设计 | `online=0` 才刷新 `lastSeenAt`，超时写 `E002` |
| 水力联合诊断 | 控制引擎内混合 | 独立诊断模块 | 已迁移 | 堵塞、泵送异常、流量传感器异常、泄漏/爆管 |

## 协议与数据

| 边界 | 旧项目 | 新项目 | 结论 |
|---|---|---|---|
| `device/sensor` | 订阅、入库、实时推送 | 同义，并严格分流 `online=0/1` | 已迁移 |
| `device/direct` | 订阅回报并发布指令 | QoS 1 单次发布，订阅设备回报 | 已迁移 |
| `device/updateTime` | 人工/设备请求校时 | 保留人工校时发布 | 有意改设计 |
| `device/behavior` | 设备上报并入库 | 不订阅 | 有意改设计 |
| `device/error` | 设备上报并入库 | 不订阅，本地规则统一报告 | 有意改设计 |
| `device/heartbeat` | 可选心跳 | 不订阅 | 明确不迁移 |
| `team/Data` / `team/command` | 中转模式 | 不订阅 | 明确不迁移 |
| 任意 `tableprefix` 历史查询 | 存在 | 固定资源 API | 有意改设计 |
| 数据库表 | 现有表 + 应用建表 | 仅使用既有表 | 有意改设计 |
| 赛方智能识别协议 | 未有最终稳定字段 | JSON 配置适配器 | 等待外部资料 |

## 关键数据表去向

| 数据表 | 新项目用途 |
|---|---|
| `t_device` | 设备查询与筛选 |
| `t_sensor_field_mapper` / `t_sensor_data` | 传感器字段映射、实时入库、历史与趋势 |
| `t_behavior_field_mapper` / `t_behavior_data` | 识别结果动态映射与历史 |
| `t_error_code_mapper` / `t_error_msg` | 故障中文映射、入库、查询与统计 |
| `t_direct_config` / `t_direct_global` | 控制定义、当前值与自动化参数 |
| `t_direct_history` | 仅旧项目的指令历史；新项目不再读写 |
| `t_operation_history` | 新项目操作历史，来源为应用层、设备、智能识别；新表从空表开始 |
| `t_water_flow_accumulator` | 累计水量持久化 |
| `t_operational_metrics_accumulator` | 实时页面水泵与加热运行时长持久化 |

## 已明确废弃的旧设计

- 不重复发布、不无限重试、不做离线指令缓存；Broker 确认不冒充设备已执行。
- 不允许前端绕过后端做 PID、安全保护或故障复位决策。
- 不接受客户端传入任意表名，不在应用启动时修改既有表结构。
- 不迁移无引用测试页、登录权限、移动端、Docker 化和文件日志系统。
