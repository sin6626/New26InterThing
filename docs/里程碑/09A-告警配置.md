# 告警配置

## 目标

比赛现场不修改状态机代码，通过中文页面按故障码控制告警行为，并保留配置修改审计。

## 规则边界

- 所有规则均可整体停用，包括核心安全规则；关闭规则后不执行相关保护、不入库、不弹窗。
- 保存记录和弹窗提醒互相独立。
- 配置保存在 `t_fault_rule_config`，后端每次产生故障副作用前读取当前配置，修改立即生效。
- 每次修改以 `fault_rule_config` 类型写入 `t_direct_history`。

## 数据库

迁移文件为 `apps/server/migrations/004-fault-rule-config.sql`，运行命令：

```text
pnpm migrate:fault-rules
```

开发机的 `26InterThing` 和队友使用的 `teamInterThing` 已同步创建并初始化 17 条规则，全部允许按比赛要求启停。

## 验证

- 故障报告器测试覆盖规则停用、仅记录、仅弹窗和默认行为。
- 水力诊断测试覆盖泄漏规则停用后不保护且不上报。
- 后端、前端和共享类型检查通过。
