# 第十里程碑：比赛交付文档与完整新旧对照

[返回重构计划目录](../重构计划.md)

## 目标

这是本轮重构的最后一个里程碑。不再扩展新业务功能，而是将前九个里程碑收口为一套可以在比赛现场直接使用、排查、验收和回退的交付材料，并逐项确认旧项目的必要业务含义已在新项目中有明确去向。

## 交付物

1. **新旧功能对照表**
   - 按设备、实时数据、历史数据、故障、行为识别、控制、自动水循环、PID、累计量、安全保护和水力诊断逐项对照。
   - 每项标记为“已迁移”、“有意改设计”、“明确不迁移”或“等待外部资料”。
   - 记录新项目对应页面、HTTP API、MQTT Topic、WebSocket 消息、数据库表和自动化测试。
   - 对旧项目的重复发布、无限重试、任意表名查询、前端作控制决策等已废弃设计说明原因。

2. **比赛现场运行手册**
   - Windows、MySQL、MQTT Broker、Node.js 和 pnpm 的前置检查。
   - `.env`、数据库连接、MQTT 连接、前后端启动、停止与重启顺序。
   - 设备编号、字段映射、控制参数、行为识别配置和故障码映射的现场检查点。
   - 正常模式、调试模式、故障复位、累计量清零的使用边界。
   - 常见问题按“页面 → HTTP → WebSocket → MQTT → MySQL”给出定位顺序。

3. **最终验收清单与结果**
   - 每个导航页面至少完成一条主链路验收。
   - 使用真实 MySQL 做只读核对；任何真实 MQTT 控制指令仍需明确的现场安全条件。
   - 在 `1366×768` 和 `1920×1080` 两种视口检查导航、表格、图表、弹窗和控制页。
   - 运行全量测试、类型检查和环境检查，形成带日期的验收结果。
   - 生产构建仍按项目约定由用户在全部开发完成后统一执行，文档给出命令和预期产物。

4. **项目入口文档收口**
   - 更新 `README.md`，使实际完成范围、启动方式、项目结构和文档入口与当前代码一致。
   - 复核 `docs/API.md`中的所有 HTTP 路由、WebSocket 消息、字段和错误响应。
   - 将里程碑目录、实施结果和最终验收文档互相链接，避免比赛现场在多份过时文档中查找。

## 实施顺序

1. 冻结功能范围，盘点新旧项目页面、路由、接口、MQTT Topic、WebSocket 消息、数据库表与配置项。
2. 建立可追溯的新旧对照表，对差异逐项引用代码或里程碑记录。
3. 对照结果若发现必要业务缺口，先单独报告并与用户确认；不在文档收口阶段自行扩大开发范围。
4. 编写现场运行手册，更新 README 和 API 文档，再做文档内链与命令可执行性检查。
5. 执行自动化验证和非破坏性真实环境核对，将结果回填到最终验收文档。
6. 由用户执行统一生产构建后，记录构建结果，将第十里程碑和总重构计划标记为已完成。

## 验收标准

- 新旧对照表覆盖所有导航页面、业务模块、设备协议、数据表和关键配置，每一项都有明确结论。
- 现场人员只阅读 README 和运行手册，即可完成启动、连接检查、正常停止、调试模式切换和常见故障定位。
- API 文档与实际路由及共享类型一致，无已删除接口或过时字段。
- 全量测试、类型检查、环境检查均通过；生产构建由用户执行并回填结果。
- 旧项目继续保留为行为参考和回退依据，不删除、不改写。

## 范围边界

- 不修改既有 MySQL 表结构、MQTT Topic 或设备上下行报文。
- 不新增登录、权限、移动端、Docker 化、文件日志系统或通用配置平台。
- 未取得赛方智能识别接口文档前，只记录配置入口和待确认项，不猜测字段或枚举。
- 不批量回算或清理历史业务数据。
- 不在未确认现场安全的情况下下发开泵、加热、清零等有状态变更的指令。

## 实施结果（2026-09-15）

- 已完成 [新旧项目对照](../新旧项目对照.md)，覆盖页面、业务模块、HTTP、MQTT、WebSocket、数据库表和明确不迁移项。
- 已完成 [比赛现场运行手册](../比赛现场运行手册.md)，收口启动、停止、配置、安全模式和故障定位流程。
- 已重写项目 [README](../../README.md)，并复核、补充 [API 文档](../API.md) 的协议边界与调试模式说明。
- 已完成 [最终验收记录](../最终验收记录.md)中的开发侧验收：环境检查、全量测试、类型检查通过；14 个真实只读 HTTP 端点返回 200；7 个页面在两种目标分辨率下完成浏览器验证。
- 未执行生产构建，按项目约定由用户统一运行 `pnpm build` 并回填结果。
- 未执行会向真实设备下发指令的人工安全验收；此项必须在现场满足水路、供电和人员安全条件后进行。

至此第十里程碑的代码、测试和交付文档已经实施完成。根据本计划第 6 步，里程碑仍待用户完成生产构建并回填后正式关闭；真实设备操作属于现场安全验收，不是待开发功能。
