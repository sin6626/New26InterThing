# New26InterThing 重构计划

## 总体目标

在不修改现有数据库结构和设备协议的前提下，将旧项目重构为容易定位、修改、测试和回退的 TypeScript Monorepo。新旧系统按模块并行对照，不一次性切换。

## 全局约束

- 不修改现有 MySQL 表结构。
- 保持旧设备 MQTT 协议与业务流程兼容。
- 按页面和业务模块纵向拆分，清理无用旧接口。
- 前端使用 Nuxt、Vue、TypeScript、Element Plus 与 Tailwind CSS。
- 后端使用 Express 与 TypeScript。
- 各阶段运行自动化测试、类型检查和必要的浏览器验证；生产构建在全部开发完成后由用户统一执行。
